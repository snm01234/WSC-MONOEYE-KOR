# data/ 공개 빌드 사양 정책

이 디렉터리는 다른 사용자가 **합법적으로 소유한 일본판 원본 ROM**에서 동일한 한국어 패치를 재현하고 검증할 수 있도록 필요한 번역·주소·구조 사양을 보관합니다.

## 공개 원칙

- 실제 빌드·감사·재현에 사용되는 활성 사양은 공개합니다.
- 원본 ROM 자체, ROM에서 추출한 바이너리 덤프, 그래픽·음원 자산은 포함하지 않습니다.
- 일부 JSON에는 올바른 ROM 위치/레코드를 fail-closed 방식으로 검증하기 위한 `jp`, `jp_full`, `source_text`, `original_text` 등의 원문 필드가 있을 수 있습니다.
- 이러한 원문 필드는 패치 대상 식별과 검증을 위한 개발 메타데이터이며, 원작의 대사·도감 내용을 독립적으로 열람하기 위한 아카이브를 만드는 것이 목적이 아닙니다.
- 빌드에 필요하지 않은 원문 덤프, 대규모 review-only worklist, 임시 추출물은 공개 대상에서 제외합니다.

## 장기 개선 방향

재현성을 유지할 수 있는 경우 원문 리터럴 검증을 다음과 같은 값으로 점진적으로 대체합니다.

- ROM 논리 주소 / 레코드 ID
- 바이트 길이와 구조 정보
- 원본 레코드 또는 본문의 SHA-256
- prefix / terminator 등 구조 바이트의 해시·hex 검증

예를 들어 빌드 도구가 사용자의 원본 ROM에서 해당 레코드를 직접 읽고 기대 SHA-256과 비교한 뒤 한국어 본문만 적용하도록 만들면, 원문 전체를 저장소에 보관하지 않고도 동일한 fail-closed 검증과 재현성을 유지할 수 있습니다.
