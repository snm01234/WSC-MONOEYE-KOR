# 건담 W 도감 명칭 전수 검토

검토 범위는 원문 ROM의 W 캐릭터 도감 `5C1500–5C2E80` 및 MS 도감 `5C4100–5C6E00`이다. 원문 일본어 레코드와 활성 한국어 카탈로그, 현재 TIP 렌더링을 대조하고 한국 공식 사이트의 현재 표기를 기준으로 판정했다. 전체 레코드별 판정은 [gundam_w_catalog_review.json](/D:/monoeye/out/script/gundam_w_catalog_review.json)에 보존했다.

확정 수정:

- `제크스`/`젝스・메키스` → `젝스`/`젝스 마키스`
- `릴리나` → `리리나`
- `메키스` → `마키스`
- `토르기스`/`토르기스Ⅲ` → `톨기스`/`톨기스Ⅲ`
- `엔들리스월츠`·`엔들리스 왈츠` → `엔드리스 월츠`
- `트레즈・크슈리나다` → `트레즈 크슈리나다`
- `윙 제로 커스텀` → 공식 제품 표기 `윙 건담 0(EW)`
- `닥터Ｊ`/`닥터－J` → `닥터 J`

공식 대조 출처: [건담W 30주년 공식 뉴스](https://kr.gundam-official.com/news/i/news/video-music/01_18008.html), [트레즈 크슈리나다 공식 캐릭터 페이지](https://kr.gundam-official.com/character/uz6sbbkw7wrfpp5q5t0t3vz1), [윙 건담 0(EW) 공식 상품 표기](https://kr.gundam-official.com/news/m2moa317pqnidjbx7ghdq0wd).

`ウイングゼロカスタム`은 게임의 기존 EW 기체명이라 공식 상품 표기 `윙 건담 0(EW)`로 고정했다. 30주년 뉴스에 새로 등장한 `윙건담 제로 클록크드 커스텀`은 별도 신기체이므로 동일 명칭으로 합치지 않았다.

참고로 현재 컴파일된 TIP 바이너리는 별도 승격 절차가 필요한 산출물이므로, 이번 변경은 활성 번역 소스·용어집·검토 목록에 우선 반영했다.
