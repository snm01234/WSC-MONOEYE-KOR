# 스테이지 타이틀 그래픽 패키지 전수 인벤토리

작성 기준: `docs/ALL_STAGE_LIST.md`와 원본 8 MiB ROM의 read-only 정적 분석.
분석 과정에서 ROM 바이트는 수정하지 않았다.

## 결론

스테이지 진입 타이틀은 동일한 패키지 형식 3개에 저장되어 있다. 각 패키지는
`타이틀 수 / 디스크립터 포인터 표 / raw 4bpp 시작 / raw 4bpp 끝` 헤더와
타이틀별 전역 타일 참조 목록, 28×18 배치 RLE를 가진다.

ROM 전체에서 배치 마커 `01 00 3B 02`는 정확히 43회 발견됐으며 아래 43개
디스크립터와 전부 일치했다. 같은 형식의 미분류 타이틀 묶음은 남지 않았다.

`ALL_STAGE_LIST.md` 46줄은 타이틀 슬롯 45개와 SPECIAL 분류 설명 1개다.
`STAGE17t/17n`, `STAGE18t/18n`이 각각 하나의 그래픽 디스크립터를 공유하므로
43개 디스크립터로 45개 타이틀 슬롯 전체가 대응된다.

| 패키지 헤더 | 디스크립터 표 | 그래픽 범위 | raw 타일 | 비공백 원본 | 타이틀 | 범위 |
|---|---|---|---:|---:|---:|---|
| `4ABD0C` | `4AC126` | `4AC146-4AF965` | 449 | 446 | 15 | 초기~홍콩 시티 |
| `4DB4B8` | `4DB90A` | `4DB92A-4DF629` | 488 | 483 | 15 | 분기 중반~우주의 소용돌이 |
| `53B9F4` | `53BD72` | `53BD8E-53EEAD` | 393 | 390 | 13 | 후반·최종·SPECIAL |
| **합계** |  |  | **1,330** | **1,319** | **43** |  |

전체 1,330타일 중 11개는 배경용 단색 타일이다. 타이틀별 사용량 합계는 공유 참조를
포함해 1,497회이며, 그중 178회가 앞 타이틀의 원본 타일 재사용이다.

기존에 후보로 묶은 330타일은 첫 패키지의 `STAGE01`~`STAGE09`가 처음 도입한
비공백 원본 타일 합계다. 첫 패키지 전체는 449타일이며 `STAGE13t`까지 포함한다.

## 타이틀별 분리

`신규`는 해당 타이틀에서 처음 도입된 물리 원본 타일 수, `공유`는 앞 타이틀에서
이미 도입된 원본을 다시 참조하는 수다. 독립 BIN/PNG를 만들 때는 신규 범위만
자르면 안 되고 공유 참조도 함께 materialize해야 한다.

## `ALL_STAGE_LIST.md`와 다른 실제 표기

- `STAGE13t`: `ホンコンシティ`가 아니라 `ホンコン・シティ`.
- `STAGE EX01/EX02`: 실제 카드는 괄호 없이 `前編`/`後編`을 둘째 줄에 표시.
- `STAGE EX03`: 실제 카드는 `「ガンダムX起動！」`처럼 낫표를 포함.
- `STAGE15n`: `石破天驚拳！` 뒤에 느낌표가 있으며 `決闘マスター・アジア`는 둘째 줄.
- `STAGE19t/20t`: 실제 카드는 `（前編）/（後編）`이 아니라 `（前）/（後）`.
- `SPECIALステージ（ランダムに進撃）`은 분류 설명이며 독립 타이틀 카드가 아니다.

## 기존 QuickSave4 표기 정정

기존 `out/patch/runtime_graphics_extract`의 `ダカールの灯火` 판정은 잘못됐다.
QuickSave4 프레임과 `4AC166-4AC3C5`의 19타일은 `STAGE01 出会い`다.
디스크립터로 재구성한 화면과 QuickSave4 framebuffer의 비공백 마스크는
245/245픽셀 일치, 차이 0픽셀이다.

`ダカールの灯火`는 두 번째 패키지의 #07이며 그래픽 원본은 해당 패키지의
전역 타일 참조와 배치 디스크립터를 통해 재구성된다.

## 재현·후속 작업 기준

1. 타이틀 식별은 화면 문자열 추정이 아니라 패키지 헤더와 디스크립터 인덱스로 한다.
2. 한글화 자산은 타이틀별 28×18 배치표와 공유 타일 의존성을 함께 보존한다.
3. 물리 타일을 교체하기 전, 같은 전역 타일을 참조하는 다른 타이틀의 영향도를 검사한다.
4. 세 패키지 밖의 stage-title형 `01 00 3B 02` 디스크립터는 현재 ROM에 없다.

기계 판독용 전체 source command와 공유 범위는
`data/stage_title_graphics_inventory.json`에 기록한다.
