# 스테이지 타이틀 한글 정적 재배치 후보

작성일: 2026-08-10

## 결과

`ALL_STAGE_LIST.md`와 ROM에서 복원한 실제 그래픽 타이틀 43개를 Galmuri11 11px로 다시
래스터화하고, 3개 타이틀 패키지의 그래픽·소스 타일 목록·504셀 레이아웃을 정적으로
재배치했다. STAGE17 t/n과 STAGE18 t/n은 각각 하나의 그래픽을 공유하므로 43개 실제
타이틀 디스크립터가 45개 스테이지 슬롯을 담당한다.

이 결과는 **실측 전 후보**다. 현재 메인 TIP은 변경하지 않았으며, 후보를 메인에
승격하려면 에뮬레이터에서 표시 시점·좌표·팔레트·전환을 확인해야 한다.

- 후보 3개 패키지 재파싱 성공
- 43개 목표 마스크 대 ROM 재구성 픽셀 차이 `0`
- 디스크립터 포인터, 레이아웃 마커, 꼬리 메타데이터 byte-exact 보존
- 변경 범위는 3개 디스크립터 블록, 3개 그래픽 블록, ROM 체크섬뿐
- 범위 밖 변경 런 `0`
- 총 변경 바이트 `21,349`, 변경 런 `4,857`
- WonderSwan 체크섬 유효
- 빌드 후 부모 TIP SHA-256 불변

이 작업은 기존에 언급된 330개만 바꾸는 작업이 아니다. 330개는 첫 패키지의
STAGE01~STAGE09에서 새로 등장하는 비공백 물리 타일 수였고, 이번 후보는 세 패키지의
43개 실제 타이틀 전체를 독립 타일 블록으로 재배치했다.

## 실측 체크리스트

후보 ROM과 같은 stem의 SaveRAM을 사용한다. 다음 항목을 우선 확인한다.

1. STAGE01: 최초 타이틀 호출 및 중앙 정렬
2. EX01·EX02: 2행 전편/후편과 행 간격
3. STAGE13t: 첫 패키지 마지막 타이틀
4. EX03: 인용부호와 `X`, 느낌표
5. STAGE15n: `석파천경권!` / `결투 마스터 아시아` 2행
6. STAGE16t·16n: `다카르의 날`과 `다카르의 등불`이 서로 뒤바뀌지 않는지
7. STAGE17t·17n 및 STAGE18t·18n: 공유 타이틀 양쪽 경로
8. STAGE19n·19t·20t: 기본/전/후 변형
9. STAGE20n·21n: 바이브레이션 전/후 변형
10. STAGE22t·22n: 동일 타이틀 양쪽 경로
11. STAGE23 및 SPECIAL01~07: 세 번째 패키지와 긴 제목

각 화면에서 글자 잘림, 위치, 배경색/글자색, 타이틀 지속 시간, 페이드·전환 직후 잔상,
다음 화면 그래픽 오염을 확인한다. 이상이 있으면 스테이지 ID와 스크린샷을 남기고 후보를
수정한다. 이상이 없더라도 사용자 승인 전에는 메인 TIP으로 승격하지 않는다.
