## 사용 방법

각 대상은 **현재 메인 TIP의 scenario runtime contract를 물리 주소 순으로 따라가며**, 대상 bundle을 중심으로 **앞 대사 5개 + 대상 대사 + 뒤 대사 5개**를 정리했다.

- 한 화자의 대사가 여러 물리 레코드로 이어지는 경우 하나의 `scenario_<bundle>` 대사로 묶었다.
- `/` 표시는 같은 대사 bundle 안에서 다음 물리 레코드/줄로 이어지는 부분이다.
- 주변 대사는 **메인 TIP의 현재 한글 본문**을 기준으로 한다.
- 정적 디코드에서 continuation 선두에 붙는 구조 바이트 `こ`는 실측 위치 식별에 방해되므로 이 문서의 한글 표시에서는 제거했다.
- **▶ 대상**의 마지막 핵심 문구는 candidate에서 확인해야 할 목표 출력이다.
- 스테이지명은 caller가 확정되지 않은 경우 추측해서 적지 않는다. 주소와 전후 한글 문맥으로 실측 위치를 찾는다.
